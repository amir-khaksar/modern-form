# 3D Flip Auth Forms

3D flip authentication UI with animated transition between login and register forms.

![Preview](./public//screenshots/Login.png)
![Preview](./public//screenshots/Register.png.png)

## Features

- 3D card flip animation (login / register)
- Responsive layout
- Modern gradient UI
- Built with React + TypeScript + Tailwind + Framer Motion

## Installation

```bash
git clone https://github.com/amir-khaksar/modern-form.git
cd 3d-flip-auth-forms
npm install
npm run dev
```
